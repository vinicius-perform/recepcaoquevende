# Recepção que Vende — Edição HOF 🌸

> **Arsenal Comercial de WhatsApp para Clínicas de Harmonização Orofacial.**  
> 120 scripts estratégicos prontos para uso imediato pela secretária: transformar dúvidas em consultas agendadas, blindar a agenda contra faltas e reativar pacientes adormecidos.

---

## 💎 Sobre o Produto

O **Recepção que Vende** foi projetado com direção de arte editorial de alto padrão (*Quiet Luxury / Beauty Editorial*), combinando o visual de páginas de lançamento premium com uma biblioteca utilitária de busca e cópia instantânea em 1 clique.

- **100% Client-Side:** Sem necessidade de banco de dados, login ou backend.
- **120 Scripts Validados:** Divididos estrategicamente em 3 Módulos e 15 Categorias clínicas.
- **Busca Inteligente:** Indexação instantânea com sinônimos clínicos de HOF (Botox, Toxina, Bioestimulador, No-show, etc.).
- **Tags de Variáveis:** Destaque visual suave para campos que devem ser preenchidos (`[Nome]`, `[Horário]`, `[Dra. Nome]`), com cópia limpa direta para o WhatsApp.
- **Scripts de Objeção / Follow-up:** Respostas prontas para desdobramentos comuns de cada conversa.

---

## 📦 Estrutura dos Módulos

### 1. Respostas que Agendam (45 scripts)
Transforme o primeiro contato e pedidos de preço em consultas avaliativas na cadeira:
- **Primeiro Atendimento** (8 scripts)
- **Preços e Valores** (10 scripts)
- **Objeções Comerciais** (9 scripts)
- **Condução para Consulta** (8 scripts)
- **Follow-up Comercial** (10 scripts)

### 2. Agenda Protegida (35 scripts)
Reduza drasticamente o no-show e mantenha a grade de horários organizada:
- **Após o Agendamento** (6 scripts)
- **Lembretes Inteligentes** (9 scripts)
- **Reagendamentos** (7 scripts)
- **Recuperação de Faltas** (7 scripts)
- **Otimização de Horários** (6 scripts)

### 3. Pacientes de Volta (40 scripts)
Aumente o LTV da clínica através de recall preventivo e reativação:
- **Leads Antigos** (8 scripts)
- **Avaliações Não Convertidas** (8 scripts)
- **Reavaliações em HOF** (9 scripts)
- **Relacionamento com Pacientes** (8 scripts)
- **Recuperação de Contatos** (7 scripts)

## 🛠️ Tecnologias Utilizadas

- **Runtime:** [Bun](https://bun.sh)
- **Framework:** [React 18](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- **Bundler:** [Vite](https://vitejs.dev)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com)
- **Tipografia:** Cormorant Garamond (editorial luxury) + DM Sans (interface)
- **Ícones:** [Lucide React](https://lucide.dev)

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
bun install

# Iniciar servidor de desenvolvimento
bun run dev

# Executar testes unitários do dataset e motor de busca
bun test

# Gerar build de produção
bun run build
```

## 🌐 Deploy no GitHub Pages

O projeto já inclui o workflow automatizado do GitHub Actions em `.github/workflows/deploy.yml`.

Para ativar a publicação automática:
1. No repositório GitHub, acesse **Settings** → **Pages**.
2. Em **Build and deployment** > **Source**, selecione **GitHub Actions**.
3. A cada push na branch `main`, o build e deploy serão feitos automaticamente.
